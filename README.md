## Structure

- PPR: Part A practice programs.

## Requirements

- JDK 17 or newer
- Windows PowerShell for the project launchers

## Run MiniBank

Open a terminal in this repository and run:

```powershell
.\LAB04\PROJECT\Run.cmd
```

Replace LAB04 with the required lab number.

## Run final project tests

```powershell
.\LAB14\PROJECT\RunTests.cmd
```

## Project progression

MiniBank develops across 14 practicals, covering classes, validation,
inheritance, interfaces, annotations, exceptions, threads, persistence,
collections, generics and testing.
